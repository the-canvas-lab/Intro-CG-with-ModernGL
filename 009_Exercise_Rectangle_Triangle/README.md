# Exercise: Rectangle and Triangle

This is a cumulative exercise reviewing programs 005–008.

## What to do

Open `exercise_rectangle_triangle.py` and follow the TODO comments. The shader programs are already set up — fill in the geometry and complete the VAO bindings.

## Concepts reviewed

- Index buffer for the rectangle (006)
- Independent VAO/VBO pairs for each object (007)
- Separate fragment shaders for different colors (008)

## Checklist

- [ ] Rectangle uses 4 unique vertices + an index buffer
- [ ] Triangle uses 3 vertices with no index buffer
- [ ] Each object has its own VBO and VAO
- [ ] Rectangle is orange, triangle is blue
